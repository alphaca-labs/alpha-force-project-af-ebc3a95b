## ID 규약

- 각 항목의 정의부는 줄 머리에 `**FR-012**` 형태로 나온다 — 검색으로 정의를 바로 찾을 수 있다.
- 다른 파일의 항목은 `04-functional-requirements.md#FR-012` 처럼 {파일명}#{ID} 평문으로 참조한다(마크다운 앵커 아님).
- ID 는 이 생성 버전 안에서만 유일하다 — 재생성하면 재번호될 수 있으므로 항상 한 버전을 통째로 소비한다.
