# 제품 정의

> 이 파일의 역할: 이 제품이 푸는 문제·솔루션·핵심 목표를 정의한다. 기능 단위 명세는 `04-functional-requirements.md` 를 본다.

## 문제 정의

내 집 마련을 계획하는 사회초년생과 예비·신혼부부는 목표 주택을 탐색하고 자산·소득·저축 여력에 맞는 자금 조달 계획을 세울 때, 복잡한 부동산 규제와 대출 조건 때문에 현실적인 매입 가능 시점과 실행 방법을 판단하기 어렵다. 기존 금융 계산기의 딱딱한 텍스트 중심 결과는 사용자가 자신의 재정적 격차를 직관적으로 이해하고 조건을 바꾸어 탐색하도록 충분한 흥미를 제공하지 못해 이탈로 이어진다.

## 솔루션 정의

**뭐해야집사냐?**는 비로그인 방문자가 목표 주택과 재정 조건을 입력하면 매입 가능성, 자금 조달 시나리오, 실행 로드맵을 산출하고, 이를 2D 픽셀 도트 게임의 캐릭터 스테이터스 형식으로 시각화하여 저장·공유할 수 있게 하는 모바일·데스크톱 웹 서비스다.

## 핵심 목표

- 사용자가 목표 주택과 현재 재정 상태 사이의 격차 및 현실적인 목표 달성 경로를 직관적으로 이해할 수 있게 한다.
- 게임형 시각화와 유머 기반 피드백을 통해 조건 조정과 시나리오 비교를 지속하도록 유도한다.
- 개인화된 결과와 실행 로드맵을 별도 가입 없이 저장하고 소셜 채널로 간편하게 공유할 수 있게 한다.
